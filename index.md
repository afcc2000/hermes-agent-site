# hermes-agent

hermes-agent is a personal AI assistant operated by André Felipe Cunha. It uses Google Sign-In (OAuth 2.0) so that a user can explicitly authorize the assistant to act on their behalf in Google services, such as reading or organizing information, only when the user requests it.
